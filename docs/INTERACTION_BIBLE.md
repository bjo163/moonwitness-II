## Interaction Principles

- Every meaningful object can reveal related objects.
- Unknown and unresolved content can still be explored.
- The Observer should not need to understand the entire universe before entering it.
- Discovery can happen before explanation.
- The interface should feel like a constellation, archive, and journey.

## Discovery Pattern

```
STORY
  ↓
JOURNEY
  ↓
NODE
  ↓
RELATED NODE
  ↓
FOLLOW TRACE
  ↓
CONSTELLATION / ARCHIVE

Constellation interaction:
- select a node
- read relationship direction/context
- follow a connected target
- open the target entity
- reset to the root trace
```

The Observer can enter from a story, from a search, or from the archive. There is no required single starting point.
