# MOONWITNESS — INTERACTION BIBLE

## Principle

> Discover, don't simply read.

The interface should let the Observer move naturally through connected fragments.

## Interaction Principles

- Every meaningful object can reveal related objects.
- Unknown and unresolved content can still be explored.
- The Observer should not need to understand the entire universe before entering it.
- Discovery can happen before explanation.
- The interface should feel like a constellation, archive, and journey.
