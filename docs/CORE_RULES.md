# MOONWITNESS — CORE RULES

> Rules should create freedom, not bureaucracy.

## 01 — STORY FIRST

Story → Structure → Code.

Code, database, UI, schema, and documentation exist to support the story.

## 02 — ONE THING, ONE HOME

```
PERSON         → PEOPLE
CHARACTER      → CHARACTERS
EVENT          → EVENTS
MESSAGE        → MESSAGES
WITNESS        → WITNESS LOG
FAULT LINE     → FAULT LINES
PAST PRESENCE  → PAST PRESENCE
PROMOTING      → PROMOTING
ERA            → TIMELINE
```

Create once. Reference everywhere.

## 03 — CONNECT, DON'T DUPLICATE

Prefer references, relationships, and links over repeated source content.

## 04 — ALIAS IS EASY

An alias is another name by default.

Do not create a new entity unless the story actually requires it.

## 05 — WITNESS DOES NOT FORCE TRUTH

A witness records an observation.

“We don't know yet” is a valid state.

## 06 — CANON CAN GROW

```
IDEA
 ↓
LORE
 ↓
CANON
```

Do not force a decision too early.

## 07 — ONE STABLE ID

Names can evolve. IDs should not.

## 08 — HUMAN LANGUAGE FIRST

Machine-readable underneath. Human-readable on top.

## 09 — CAPTURE FIRST, REFINE LATER

Ask only:

```
WHAT IS IT?
WHERE DOES IT BELONG?
WHAT DOES IT CONNECT TO?
```

Then capture it.

## 10 — NO PREMATURE COMPLEXITY

Complexity must earn its place.

Do not add services, abstractions, workflows, permissions, schemas, or automation without a real need.

## 11 — HELP THE CREATOR

Make it easy to:

**CREATE · EDIT · CONNECT · ARCHIVE · REOPEN · DISCOVER · PROMOTE**

## 12 — ARCHIVE, DON'T DESTROY

Preserve old material when possible.

A forgotten story may become a discovered story.

## 13 — UNKNOWN IS VALID

Use:

**UNKNOWN · UNRESOLVED · MYSTERY**

when appropriate.

## 14 — NARRATIVE ROLES ARE CONTEXTUAL

Villain, Dreamer, Runaway, Seduction, Fault Line, Sanity's Last Breath, and Past Presence are narrative tools.

## 15 — BUILD FOR DISCOVERY

The system should support:

```
CHARACTER
 ↓
EVENT
 ↓
WITNESS
 ↓
MESSAGE
 ↓
FAULT LINE
 ↓
PAST PRESENCE
 ↓
PROMOTING
 ↓
ERA
```

## 16 — THE SIMPLE TEST

Before adding something new:

**Does it help us CREATE, CONNECT, DISCOVER, REMEMBER, CHANGE, or MOVE FORWARD?**

If not, it probably does not belong yet.

## FINAL RULE

> Minimum Rules. Maximum Story.
>
> Structure the chaos.
>
> Do not kill the chaos.
