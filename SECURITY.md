# Security Policy

## Supported state

Until MoonWitness has a tagged production release, the current `main` branch is the only supported code line.

## Reporting a vulnerability

Please do not publish exploit details, credentials, tokens, private data, or reproducible attack instructions in a public issue.

Use GitHub's private **Report a vulnerability** / Security Advisory flow for this repository when it is available. If that private flow is unavailable, contact the repository owner privately through GitHub before disclosing sensitive technical details.

Include:

- affected commit or route,
- impact,
- minimal reproduction details,
- whether the issue is already being exploited,
- any safe mitigation you have identified.

## Scope

Security reports may include dependency vulnerabilities, unsafe content handling, server-side file exposure, deployment configuration, authentication if introduced later, or accidental disclosure of secrets/private data.

Do not include real credentials in a report.
