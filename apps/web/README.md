# MoonWitness Web

The first web interface to the MoonWitness platform.

## Principle

This app is an interface to the platform. Canonical content remains in the repository `data/` layer.

## Commands

From repository root:

```bash
npm install
npm run web:dev
npm run web:build
npm run web:start
```

From this directory:

```bash
npm install
npm run dev
npm run build
npm run start
```

## Current MVP

- Moon / Hero
- Witness flow
- Crew
- First Event + Witness + Message
- Past Presence
- Audit / Evaluation / Balancing / Promoting
- Next Phase
